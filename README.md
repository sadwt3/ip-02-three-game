## 作品列表

### 1. 几何构成（静态）static.html
8×8 棋盘式圆点阵列：双重 for 循环批量生成重复元素，黑白两色交错形成节奏；全部绘制在 setup() 中完成，不使用 draw() 循环。技术：p5.js

### 2. 交互动态 dynamic.html
小球随时间自动运动、触碰画布边缘反弹；半透明背景保留运动轨迹；鼠标横向移动（mouseX）实时控制小球颜色；鼠标位置绘制跟随方块。draw() 循环 + 鼠标交互。技术：p5.js

### 3. 贪吃蛇（附加作品）snake.html
方向键 / WASD 控制移动，空格键暂停；场上多个食物与随机障碍物，撞墙、撞自己或撞障碍物游戏结束；计分、最高分（localStorage）与随分数提速。技术：原生 Canvas

## 如何查看
